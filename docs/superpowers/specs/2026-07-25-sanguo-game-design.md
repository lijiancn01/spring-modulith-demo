# 三国群英传单机版 - 设计文档

## 概述

基于Web技术栈的三国群英传单机版策略游戏，国风水墨视觉风格，包含完整的大地图、内政、征兵、武将、战斗系统。

## 技术栈

- **前端**：HTML5 + CSS3 + 原生JavaScript（ES6+）
- **渲染**：Canvas 2D（地图+战斗）+ DOM（UI面板）
- **存档**：localStorage
- **风格**：国风水墨风（CSS变量+Canvas绘制）

## 架构设计

### DOM + Canvas 混合架构

- **DOM层**：游戏UI面板、菜单、武将列表、城市信息、对话系统
- **Canvas层**：大地图渲染、战斗场景渲染
- **数据层**：纯JS对象管理游戏状态

## 核心系统设计

### 1. 游戏主循环

回合制：玩家行动 → AI行动 → 事件结算 → 下一回合

阶段：
1. 战略阶段：大地图操作，选择城市进行内政
2. 行军阶段：选择武将带兵，指定目标行军
3. 战斗阶段：遭遇战斗，进入战斗场景
4. 回合结束：AI决策，随机事件，回合+1

### 2. 大地图系统

- 中国地图简化版，约30个城池
- 城池以节点显示，连线表示通路
- 不同势力用不同颜色标识
- 点击城池进入内政/出兵操作
- 行军路线动态显示

### 3. 城市内政系统

每个城市属性：
- 农业（影响粮草产出）
- 商业（影响金钱产出）
- 民心（影响征兵数量和城防）
- 城防（防御力）
- 兵力（驻军数量）

内政操作：
- 开发：分配武将开发农业/商业
- 征兵：消耗金钱粮草征兵
- 搜索：搜索在野武将
- 训练：提升兵力训练度

### 4. 武将系统

属性：
- 武力：影响物理攻击
- 智力：影响策略效果和军师技
- 政治：影响内政开发效果
- 统率：影响带兵上限和部队战力
- 魅力：影响搜索和忠诚
- 忠诚度：低于阈值可能被策反

武将技（战斗中释放）：
- 旋风斩、火牛阵、落雷、突刺、旋樱 等
- 消耗技力，有冷却

军师技（战前释放）：
- 增加士气、降低敌军士气、伏兵 等

### 5. 战斗系统

战场布局：横版对战，双方各5个武将位

兵种相克：
- 步兵 > 弓兵 > 骑兵 > 步兵

战斗流程：
1. 战前：选择出战武将、军师技
2. 开战：双方士兵自动对战
3. 武将技：手动/自动释放武将技
4. 单挑：武将可发起1v1单挑
5. 胜负：一方全灭或撤退

### 6. AI系统

AI决策逻辑：
- 优先发展薄弱城市
- 兵力充足时进攻弱城
- 搜索在野武将
- 防守时征兵增援

### 7. 存档系统

使用 localStorage 存储完整游戏状态，支持3个存档位。

## 视觉风格

- 背景：宣纸纹理底色（#f5f0e8）
- 文字：毛笔字体效果
- 城池：水墨圆点+毛笔字标注
- 山水：Canvas绘制简约山水元素
- 战斗：水墨风特效（墨迹飞溅、水墨晕染）
- UI面板：半透明宣纸质感边框

## 验收标准

1. 能启动并正常运行
2. 大地图可交互，点击城市可查看信息
3. 内政操作可执行并看到效果
4. 行军和战斗流程完整
5. AI能自动行动
6. 存档/读档功能正常
7. 国风水墨视觉风格一致
